# Место — MVP

Статическая страница HTML + JavaScript: выбор координат на карте, радиус 2–50 км, загрузка настоящих высот, 3D-перстень с рельефом. Регулируются выраженность рельефа, размер превью и материал.

Публичная версия: https://skvoch.github.io/geo/

Локальный запуск: `node server.mjs`, затем http://127.0.0.1:4173. GitHub Actions автоматически публикует содержимое `dist` в GitHub Pages после каждого обновления ветки `main`.

Нужны интернет и WebGL. Three.js и Leaflet загружаются с CDN, карта — OpenStreetMap. Высоты — открытые Mapzen Terrain Tiles на AWS: https://registry.opendata.aws/terrain-tiles/ . Декодирование Terrarium: R × 256 + G + B / 256 − 32768 метров. Глобальное покрытие включает Россию, разрешение и качество различаются по регионам. Источники и атрибуция: https://github.com/tilezen/joerd/blob/master/docs/attribution.md . Доступность сервисов из российских сетей отдельно не проверена.

Для MVP высоты считываются на сетке 97 × 97 без интерполяции внутри исходного пикселя, поверхность интерполируется между точками. Радиус задаёт круг вокруг выбранной точки с приближённым пересчётом километров в градусы. В перстне рельеф квадратного участка, вписанного в выбранный круг, расположен на широкой верхней площадке. Края рельефа плавно сведены к гладкому корпусу, дужка снизу сужается. Это художественная трансформация, не геодезическая проекция или готовая модель для литья. Размер — относительный размер превью; экспорт и физические размеры пока не реализованы.

При ошибках данные не заменяются выдуманным рельефом. Предыдущая модель сохраняется с указанием ошибки. Поверхности предварительные: проверка замкнутости для производства не выполнялась.


Обновление перстня: единая замкнутая сетка со скруглённым сечением, общий световой переход между рельефом и корпусом. Высоты считаются относительно среднего уровня верхнего участка; низины углубляются с плавным ограничением глубины. Локальное сглаживание 3 × 3 сохраняет крупные формы. Проверка node signet-check.mjs проверяет выступы/впадины, замкнутость рёбер и отверстие для пальца на синтетическом рельефе; это не сертификация модели для изготовления.
